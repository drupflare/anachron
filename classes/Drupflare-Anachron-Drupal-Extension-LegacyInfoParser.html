\Drupflare\Anachron\Drupal\Extension LegacyInfoParser

Lets an extension that declares an older core run, when the site opts in.

Core marks an extension core_incompatible when its core_version_requirement excludes the running release, and refuses to enable it. With the switch on, the flag is cleared and the declared requirement is kept in anachron_core_requirement, so a report can say how many extensions ran past what they declared. Passing the check says nothing about whether the code works; that is what running it finds out.
