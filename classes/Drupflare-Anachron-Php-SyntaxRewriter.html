\Drupflare\Anachron\Php SyntaxRewriter

Rewrites the curly string offset syntax PHP 8.0 removed ($str{0}) to square brackets.

Only the two braces of each offset change, each to a single character, so the output keeps the input's line count and every line number in a stack trace.
